# Rice Shop Manager

Android app with Nasreen 102/107, Suber 79/85, Tajmahal 40/45, Nasreen 2 95/102.

## Cloud APK build (recommended for your government laptop)
Upload this project to GitHub, open **Actions**, choose **Build Rice Shop APK**, click **Run workflow**, then download the `rice-shop-debug-apk` artifact.

## Gradle Wrapper
`gradlew`, `gradlew.bat`, and `gradle/wrapper/gradle-wrapper.properties` are included and target Gradle 8.9. The wrapper JAR is intentionally not included here; the GitHub Actions workflow uses the official Gradle setup action, so you can build the APK without installing Android Studio.
